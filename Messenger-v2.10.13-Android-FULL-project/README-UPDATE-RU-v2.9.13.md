# Обновление мессенджера — v2.9.13

Изменения:
- Свой профиль теперь можно открыть кнопкой «Посмотреть профиль» в настройках профиля; фон профиля виден и владельцу.
- На телефоне системная кнопка «Назад» возвращает из переписки к списку чатов. Кнопка-стрелка в интерфейсе также возвращает к списку.
- В личной переписке у отправленных сообщений одна галочка до прочтения и две галочки после того, как собеседник открыл чат с сообщением.
- Убраны кнопки ручного обновления контактов и уведомлений из заголовка. Контакты обновляются автоматически; разрешение на уведомления запрашивается при входе, если браузер поддерживает Notifications.

Важно:
- Уведомления зависят от разрешения браузера/Android. Сайт по HTTP на публичном IP может не поддерживать Web Notifications; для надёжной работы нужен HTTPS. Нельзя принудительно включить уведомления, если пользователь или система запретили их.
- Отметки прочтения работают для личных сообщений и требуют, чтобы получатель был подключён к серверу и открыл соответствующую переписку.
- Текущий временный HTTP-режим не подходит для настоящих паролей или конфиденциальных сообщений. Настройте HTTPS и безопасное шифрование перед реальным использованием.
