# Messenger — обновление списка чатов и навигации

Что изменено:
- При входе сначала открывается список чатов, а не общий чат.
- По умолчанию в личных чатах показываются только пользователи, с которыми уже есть личная переписка.
- Поиск показывает всех пользователей по совпадению никнейма; найденного пользователя можно открыть и начать новый разговор.
- При открытии чата список остальных чатов скрывается.
- Кнопка «←» возвращает к списку чатов.
- При открытии переписки показывается её конец.
- Кнопка «↓ К последнему сообщению» появляется, если прокрутить историю вверх, и скрывается у конца переписки.

## Установка на существующий сервер

Сначала сделайте резервную копию данных и исходников. В каталоге проекта выполните:

```bash
cd /root/messenger-project
tar -czf /root/messenger-before-chat-navigation.tar.gz frontend backend/server.js
```

Распакуйте этот архив в отдельную временную папку, а затем скопируйте из неё `frontend/index.html`, `frontend/style.css`, `frontend/app.js` и `backend/server.js` в соответствующие места проекта. Не заменяйте `data/`, `.env` или `docker-compose.yml`.

Пересоберите контейнер:

```bash
docker compose up -d --build app
docker compose ps
docker compose logs --tail=60 app
```

После установки обновите страницу браузера сочетанием Ctrl+F5.

Важно: это обновление навигации и списка чатов. Оно не включает HTTPS, E2EE или прямую передачу больших файлов.


## v2.7: фото и выход
- Поддерживаемые изображения показываются прямо в переписке и открываются в полноэкранном просмотрщике внутри мессенджера.
- Кнопка выхода запрашивает подтверждение.
- В этой реализации фотографии всё ещё хранятся на VPS, чтобы собеседник мог их получить. Хранение только на телефоне без сервера требует отдельной P2P-передачи и в эту версию не входит.
