# Обновление мессенджера — v2.9.14

## Изменения
- Сохранены изменения v2.9.13: просмотр собственного профиля и фона, системная кнопка «Назад» в Android, индикаторы прочтения (✓ / ✓✓), удаление кнопок ручного обновления и уведомлений из заголовка.
- Добавлена адаптация высоты интерфейса к видимой области экрана на Android при открытии и закрытии экранной клавиатуры. Заголовок чата с именем собеседника остаётся в верхней части, история сообщений прокручивается отдельно, поле ввода остаётся в доступной области.
- Используются `visualViewport`, `100dvh`, `viewport-fit=cover` и `interactive-widget=resizes-content` с fallback на `innerHeight`.

## Проверки, выполненные перед упаковкой
- `node --check frontend/app.js` — синтаксис JavaScript проверен.
- `node --check backend/server.js` — синтаксис backend JavaScript проверен.
- Проверены наличие разметки заголовка чата, поля ввода, кнопки возврата, индикатора прочтения и серверного обработчика `read`.

## Ограничения
- Поведение клавиатуры зависит от версии Android и браузера; нужна проверка на реальном телефоне, так как здесь невозможно физически открыть клавиатуру Android.
- Уведомления требуют разрешения пользователя и поддержки браузером; на публичном HTTP без HTTPS они могут быть недоступны.
- Перед использованием реальных паролей/личных данных необходимо настроить HTTPS и проверить шифрование.


## v2.9.15 — кнопка просмотра собственного профиля
Кнопка «Смотреть профиль» перенесена из окна настройки профиля в строку рядом с собственной аватаркой. На узком экране используется компактная кнопка с подсказкой.
