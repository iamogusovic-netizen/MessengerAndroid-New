# Мессенджер — IP-only VPS сборка

Подготовленный прототип настольного мессенджера на Electron/Node.js с поиском по нику и realtime-соединением. Для VPS без домена см. `deploy/README-VPS-RU.md`.

Важно: развёртывание использует внутренний TLS-сертификат Caddy. Чтобы HTTPS и WebCrypto работали на Windows-клиентах, корневой сертификат Caddy нужно вручную установить в доверенные корневые сертификаты на каждом устройстве. Прототип не проходил независимый аудит безопасности и не предназначен для чувствительных данных без дополнительной проверки.
