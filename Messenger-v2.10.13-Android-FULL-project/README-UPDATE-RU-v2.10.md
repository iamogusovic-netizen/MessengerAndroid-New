# Messenger v2.10 — действия с сообщениями

## Что добавлено
- На компьютере у каждого сообщения есть меню `⋯` с действиями.
- На телефоне меню действий открывается долгим нажатием на сообщение.
- Пересылка в личный чат или общий чат с возвратом в исходный чат после отправки.
- Копирование текста сообщения в буфер обмена.
- Редактирование собственных текстовых сообщений с отметкой «изменено».
- Удаление только у себя; автор также может удалить своё сообщение у всех.
- Сервер проверяет права на редактирование и удаление. Удалённые только у себя сообщения скрываются для данного аккаунта и сохраняются для остальных.
- Для событий редактирования и удаления используется WebSocket, чтобы интерфейсы других участников обновлялись без перезагрузки.

## Обновление на сервере
Сначала сделайте резервную копию проекта и загрузите ZIP на сервер. Затем обновите `frontend/` и `backend/server.js`, пересоберите контейнер `app` и проверьте `docker compose logs --tail=50 app`.

Данные пользователей в `data/`, `.env` и конфигурация Caddy не заменяются этим архивом.
