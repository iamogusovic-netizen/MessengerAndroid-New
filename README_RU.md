# MessengerAndroid-New

Чистый Android-проект WebView-оболочки мессенджера.

## Сборка
GitHub Actions автоматически собирает debug APK при push в `main` или вручную через Actions → Build Android APK → Run workflow.
Артефакт: `MessengerAndroid-New-debug`.

## Важные ограничения
- Приложение загружает существующий веб-мессенджер по адресу `http://89.125.121.18`.
- Исходники сайта и backend в этом репозитории отсутствуют. Интерфейс сайта и серверная обработка нескольких вложений здесь не меняются.
- Встроенная Android-галерея вызывается через HTML file chooser. Множественный выбор передаётся странице как массив URI только если HTML-форма сайта использует `multiple`.
- Системная тема Android не меняется приложением. Тёмное оформление задаётся только окну приложения и системным панелям.
- Перед релизом необходимы проверка GitHub Actions и тест на физическом устройстве (разрешения фото/видео, отправка нескольких вложений, поворот экрана, Android 13/14/15).

## Загрузка в новый репозиторий
Загружайте содержимое этой папки в корень нового репозитория, не саму папку-обёртку.
