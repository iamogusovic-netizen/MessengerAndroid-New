# MessengerAndroid-New

Android WebView-оболочка существующего веб-мессенджера.

## Что включено
- Один Android-модуль `app` в корне проекта — без вложенных копий старых проектов.
- Сборка APK через GitHub Actions.
- Java 17, Android SDK 35 и Gradle 8.9 закреплены в workflow.
- Тёмное оформление Android-окна и системных панелей приложения.
- Приложение не вызывает API изменения глобального режима дня/ночи Android.
- Splash screen на Android 12+ с иконкой приложения; на старых версиях — тёмный фон запуска.
- WebView с аппаратным ускорением и отключённым принудительным затемнением веб-страницы.
- Нативная панель выбора медиа, вкладки «Все / Фото / Видео» и множественный выбор для HTML file input с `multiple`.

## Сборка APK
1. Загрузить ВСЁ содержимое архива в корень нового GitHub-репозитория (включая скрытую папку `.github`).
2. Убедиться, что ветка называется `main`.
3. Открыть вкладку Actions и выбрать `Build Android APK`.
4. Дождаться зелёного статуса.
5. Скачать артефакт `MessengerAndroid-New-debug-apk`; внутри будет `app-debug.apk`.

Workflow сам устанавливает Gradle 8.9, JDK 17 и Android SDK. Gradle Wrapper не требуется для этого способа сборки, поскольку runner устанавливает закреплённую версию Gradle перед запуском сборки.

## Важные ограничения интеграции
- Приложение открывает существующий веб-сайт `http://89.125.121.18`. Исходников сайта и backend в этом репозитории нет.
- Нативная галерея возвращает выбранные URI в WebView. Множественный выбор полноценно отправится только если веб-страница запрашивает `<input type="file" multiple>` и её JS/backend умеют обрабатывать несколько файлов.
- Поэтому визуальную интеграцию панели с конкретным дизайном сайта и успешную отправку нескольких вложений нельзя подтвердить только этим Android-репозиторием.
- Для HTTP-адреса включён cleartext traffic, как в исходном проекте. Для реального релиза рекомендуется перевести сайт на HTTPS.
- Системная тема устройства намеренно не меняется. Тёмные цвета относятся только к окну приложения/системным панелям приложения.
- APK требует тестирования на физическом Android-устройстве, включая разрешения фото/видео на Android 13/14/15.

## Проверки перед релизом
- GitHub Actions завершился успешно.
- Приложение открывает сайт и сохраняет сессию.
- Галерея открывается, показывает доступные фото/видео и корректно работает с частичным доступом Android 14+.
- Выбор одного и нескольких файлов проверен на стороне веб-формы.
- Переключение темы телефона не происходит при запуске/закрытии приложения.
